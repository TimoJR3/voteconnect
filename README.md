# VoteConnect

**Платформа соучастия района: жители распределяют бюджет и договариваются, администрация получает готовый отчёт для совета.**
Наверху ленты — не самое громкое, а то, что поддерживают люди с разными взглядами.

- Сайт: https://timojr3.github.io/voteconnect/
- Демо-тур (2 минуты, без регистрации): https://timojr3.github.io/voteconnect/app.html?demo=1&tour=1
- Для инвесторов: https://timojr3.github.io/voteconnect/investors.html
- Приложение: https://timojr3.github.io/voteconnect/app.html — открывается на телефоне и ставится на главный экран

## Что внутри

| Раздел | Что делает |
|---|---|
| Бюджет района | Инициативное бюджетирование: корзина проектов в пределах 15 млн ₽, отбор по голосам, итоги и прошлый цикл |
| Кабинет администрации | Участие, воронка бюджета, представленность групп, выгрузка CSV |
| Отчёт для совета | Готовый документ в PDF: с чем согласны все группы, итоги бюджета, рекомендации |
| Лента района | Посты с фото и полоской поддержки по группам мнений. Вкладка «Слепое пятно» — что обсуждают другие группы, но не видит ваша |
| Компас взглядов | 12 вопросов о районе → процент совпадения с каждым кандидатом. Ответы не покидают устройство |
| Карта согласия | Голосование по коротким утверждениям, алгоритм находит группы мнений и общие точки |
| Кандидаты | Профили, позиции, обещания, вопросы жителей |
| Инициативы | Предложения жителей с порогом подписей. Редактор — **Yoopta-Editor** |
| Помощник | Помнит район, интересы и мнения жителя — модель памяти как в **ai-memory-service** |
| События | Календарь, «Пойду», экспорт в .ics, поиск участка |
| Кабинет кандидата | Аудитория, вопросы по поддержке, темы округа, черновики ответов с ИИ |
| Ещё | Обещания, опросы, дебаты по «правилу моста», академия, профиль с настройками приватности |

## Как показывать

1. `app.html?demo=1&tour=1` — демо-тур из 11 шагов без регистрации. Стрелки ← → листают, Esc закрывает.
2. `app.html?reset=1` — сбросить демо и начать с регистрации.
3. Кнопка «Открыть на телефоне» показывает QR-код.

## Открытые компоненты

- [Yoopta-Editor](https://github.com/yoopta-editor/Yoopta-Editor) — редактор инициатив (`editor/`, собирается в `assets/js/editor.bundle.js`).
- [ai-memory-service](https://github.com/Darginec05/ai-memory-service) — модель памяти помощника: факты, интересы, мнения, события; новое значение заменяет старое. В демо память хранится в браузере; в продукте — в сервисе.
- Фотографии — [Unsplash](https://unsplash.com), аватары — DiceBear Notionists (CC0), шрифт Onest (OFL). Всё хранится в репозитории: сайт не обращается к сторонним сервисам.

## Запуск

Сайт статический, сборка нужна только для редактора:

```bash
cd editor && npm install && npm run build
```

```bash
npx serve .
```

## Структура

```
index.html            — сайт
investors.html        — страница для инвесторов и грантовых фондов
app.html              — приложение
assets/css/style.css  — дизайн-система (светлая и тёмная темы)
assets/js/app.js      — логика приложения
assets/js/data.js     — демо-данные (вымышленный город Новоград)
assets/js/icons.js    — набор иконок
assets/img, avatars, fonts — локальные фото, аватары и шрифт
editor/               — исходник редактора на Yoopta
styles.html           — сравнение стилей, из которого выбран текущий
docs/                 — аудит (AUDIT.md), текст заявки и идеи развития
```

Демо: город, кандидаты, партии и события вымышлены. Лицензия [MIT](LICENSE).
