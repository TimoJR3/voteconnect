# VoteConnect

Демо инициативного бюджета на примере Махачкалы, Республика Дагестан. Жители выбирают до трёх проектов. На экране итогов видно, какие проекты проходят в рамках 15 млн ₽. Для администрации есть отчёт, который можно распечатать или сохранить в PDF. Проекты, авторы идей, суммы и голоса вымышлены. Голос хранится в браузере.

## Как открыть

[Главная на GitHub Pages](https://timojr3.github.io/voteconnect/) ведёт в демо. Для локального запуска из корня репозитория выполни `node tests/serve.js` и открой [главную](http://127.0.0.1:4173/) или [проекты](http://127.0.0.1:4173/app.html?demo=1#/vote).

## Файлы

- `index.html` — главная. `privacy.html` и `investors.html` — текстовые страницы.
- `app.html`, `assets/js/app.js`, `assets/js/data.js` — проекты, итоги, отчёт и демо-данные.
- `assets/css/`, `sw.js`, `manifest.webmanifest` — стили, офлайн-кэш и установка на телефон.
- `tests/` — проверки голосования и безопасности.

## Тесты

```sh
cd tests
npm ci
npx playwright test
```

Локально используется Microsoft Edge. В GitHub Actions используется Chromium.
