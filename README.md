# VoteConnect 🗳️

**Гражданская социальная сеть, которая объединяет, а не разделяет.**

VoteConnect помогает жителям разобраться в выборах, найти своих кандидатов и договориться друг с другом. В отличие от обычных соцсетей, лента продвигает не самое громкое и скандальное, а то, что поддерживают люди с **разными** взглядами.

> 🔗 **Демо:** https://timojr3.github.io/voteconnect/
> 📄 **Заявка на грант:** [docs/GRANT_PITCH.md](docs/GRANT_PITCH.md)
> 💡 **Банк идей:** [docs/IDEAS.md](docs/IDEAS.md)

## Три функции, которых нет больше ни у кого

| | Функция | Суть |
|---|---|---|
| 🌉 | **Лента с «рейтингом моста»** | Выше поднимаются посты, которые одобряют люди из разных групп мнений. Фейки получают «контекст от сообщества». |
| 🤝 | **Карта согласия** | Жители голосуют по коротким утверждениям, алгоритм находит группы мнений и то, что поддерживают *все*. Готовая повестка для депутатов. |
| 🧭 | **Компас взглядов** | 12 утверждений о жизни города → процент совпадения с каждым кандидатом. Считается на устройстве, данные никуда не уходят. |

## Все модули прототипа

| Модуль | Что делает | Экран |
|---|---|---|
| Лента | Новости, посты кандидатов и жителей, проверенные источники, ИИ-модератор тона | `#/feed` |
| Компас взглядов | Тест совпадения с кандидатами с разбором по каждому утверждению | `#/compass` |
| Карта согласия | Кластеризация мнений в стиле Pol.is, «живые» участники | `#/consensus` |
| Опросы | Результаты в реальном времени, видны после голосования | `#/polls` |
| Кандидаты | Профили, позиции, вопросы жителей, % ответов | `#/candidates` |
| Трекер обещаний | Статусы обещаний со ссылками на документы | `#/promises` |
| Календарь | Месячная сетка, «Пойду», экспорт в `.ics`, поиск участка | `#/calendar` |
| Группы и дебаты | Дискуссии по **Правилу моста**: сначала перескажи позицию оппонента | `#/groups` |
| «Голосуй за меня» | Гражданские инициативы с порогом подписей и обязательным ответом кандидатов | `#/initiatives` |
| Академия | Уроки по 3 минуты + квизы, XP и значки | `#/academy` |
| Гражданский паспорт | Профиль, уровень, значки, приватность, экспорт и удаление данных | `#/profile` |

## Запуск

Сборка не нужна — это статический сайт на чистом HTML/CSS/JS.

```bash
# любой статический сервер, например:
npx serve .
# или
python -m http.server 8000
```

Или просто откройте `index.html` в браузере.

## Структура

```
index.html            — лендинг для презентации (проблема, решение, отличия, план)
app.html              — интерактивный прототип
assets/css/style.css  — дизайн-система (светлая и тёмная темы, адаптивность)
assets/js/data.js     — демо-данные (вымышленный город Новоград)
assets/js/app.js      — логика приложения (роутинг, модули, расчёты)
docs/GRANT_PITCH.md   — текст для грантовой заявки
docs/IDEAS.md         — идеи развития и как выделиться
```

## Принципы

1. **Беспартийность.** Платформа не агитирует ни за кого, все кандидаты получают одинаковые инструменты.
2. **Приватность по умолчанию.** Политические взгляды — особая категория персональных данных. Компас считается на устройстве, взгляды по умолчанию видны только владельцу.
3. **Открытость.** Открытый код, открытая методика, открытые агрегированные данные.
