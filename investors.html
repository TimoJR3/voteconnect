Где мы сейчас

Готово

  • Работающий прототип: 19 экранов для жителей, администрации и кандидатов

  • Карта согласия и отчёт для совета в PDF
  • Приложение для телефона, работает без интернета, есть режим крупного шрифта для старшего поколения

  • Показатели социального эффекта для отчёта грантодателю: молодёжь, старшее поколение, новые участники, бумажные анкеты
  • Открытые компоненты: редактор Yoopta-Editor, модель памяти ai-memory-service
