# Тест-кейсы безопасности и утечек данных

28 автотестов в реальном браузере (Playwright). Запускаются автоматически при каждом изменении в репозитории — вкладка **Actions** на GitHub, сценарий «Безопасность».

Запуск на своём компьютере:

```bash
cd tests && npm ci && npx playwright test
```

## Утечка данных

| ID | Что проверяем | Как | Ожидаемый результат |
|---|---|---|---|
| SEC-01 | Сайт не обращается к сторонним серверам | Обход всех страниц и 19 экранов, поиск, QR-код, редактор; перехват всех запросов браузера | Все запросы — только к своему сайту |
| SEC-02 | Ответы Компаса, голоса и посты не уходят по сети | Пройти Компас, проголосовать на Карте согласия и за бюджет, написать пост, спросить помощника | Нет запросов, кроме загрузки файлов сайта; нет запросов с параметрами |
| SEC-03 | Имя, адрес и телефон не попадают в адреса запросов | Регистрация с тестовыми данными, обход экранов | Ни один адрес запроса не содержит имя, улицу или телефон |
| SEC-04 | Номер телефона не сохраняется | Регистрация, проверка хранилища браузера | Имя сохранено, телефона нет |
| SEC-05 | Адрес из формы на сайте не остаётся в адресной строке | Ввести адрес на главной и перейти в приложение | Адрес подставлен в форму, адресная строка очищена |
| SEC-06 | Аватар не раскрывает имя | Регистрация, проверка адресов всех картинок | Имени нет ни в одном адресе картинки |
| SEC-07 | «Удалить всё» стирает личные данные | Регистрация, ответы Компаса, удаление | Имени и ответов в хранилище нет, открывается регистрация |
| SEC-08 | Выгрузка «Мои данные» содержит только данные владельца | Скачать файл с данными | Есть имя владельца, нет паролей, токенов и телефона |

## Внедрение кода (XSS)

Во всех кейсах вводится HTML с вредоносными обработчиками. Тест проверяет, что разметка не попала в страницу — не только что код не выполнился. Иначе политика безопасности могла бы скрыть ошибку экранирования.

| ID | Что проверяем | Как | Ожидаемый результат |
|---|---|---|---|
| SEC-09 | Имя пользователя | Зарегистрироваться с HTML вместо имени | Имя показано текстом ровно как введено, внедрения нет |
| SEC-10 | Пост и комментарий | Опубликовать HTML в посте и комментарии | Показано текстом |
| SEC-11 | Помощник, поиск, дебаты | Ввести HTML в чат, строку поиска и аргумент | Показано текстом |
| SEC-12 | Инициатива и редактор Yoopta | HTML в заголовке и тексте инициативы | Показано текстом |
| SEC-13 | Адрес страницы | HTML в параметре адреса и в разделах `#/candidate/…`, `#/group/…`, `#/lesson/…` | Внедрения нет, открывается безопасный экран |
| SEC-14 | Подменённое хранилище браузера | Записать HTML в имя, посты, чат, память, инициативы, комментарии | При выводе всё экранируется и очищается повторно |
| SEC-15 | Очистка текста инициатив | Обработчики, скрипты, `javascript:`-ссылки, iframe, svg | Остаются только заголовки, абзацы, жирный, курсив, маркер — без атрибутов |
| SEC-16 | Политика безопасности браузера (CSP) | На каждой странице вставить скрипт и обработчик в обход приложения | Браузер блокирует выполнение |

## Выгрузки, ссылки и заголовки

| ID | Что проверяем | Как | Ожидаемый результат |
|---|---|---|---|
| SEC-17 | CSV-выгрузка не исполняется как формула Excel | Значения `=`, `+`, `-`, `@`; скачать CSV в кабинете администрации | Опасные значения начинаются с апострофа |
| SEC-18 | Внешние ссылки не получают доступ к нашей вкладке | Проверить все внешние ссылки | У всех `rel="noopener noreferrer"` |
| SEC-19 | Заголовки безопасности | Проверить каждую страницу | Есть CSP (`script-src 'self'`, `object-src 'none'`, `base-uri 'self'`) и политика реферера |
| SEC-20 | Стабильность | Открыть все экраны и пройти демо-тур | Ни одной ошибки JavaScript |

## Проверки кода и репозитория

| ID | Что проверяем | Ожидаемый результат |
|---|---|---|
| SEC-21 | Встроенные скрипты и обработчики в HTML и шаблонах | Нет — совместимо со строгой CSP |
| SEC-22 | Подключение ресурсов со сторонних серверов | Нет: фото, аватары, шрифт и библиотеки хранятся на сайте |
| SEC-23 | Отправка данных из кода (`fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`) | Не используется |

| SEC-27 | Уязвимости в зависимостях (`npm audit`) | Нет уязвимостей уровня high и выше — проверяется в GitHub Actions |

## Что найдено и исправлено при подготовке тестов

| Находка | Риск | Исправление |
|---|---|---|
| Очистка текста инициатив разбирала HTML через `innerHTML` | Картинка с вредоносным `onerror` срабатывала прямо во время очистки | Разбор через `DOMParser` — инертный документ; содержимое `script`, `style`, `iframe`, `svg` отбрасывается |
| На страницах не было политики безопасности (CSP) | При любой ошибке экранирования внедрённый код выполнился бы | Строгая CSP на всех страницах |
| Встроенные обработчики и скрипт | Несовместимы со строгой CSP | Перенесены в файлы |
| Сохранённый текст инициатив выводился без повторной очистки | Подмена хранилища могла внедрить разметку | Очистка при каждом выводе |
| CSV-выгрузка без защиты от формул | Ячейка `=HYPERLINK(...)` выполнилась бы в Excel | Апостроф перед опасными значениями |
| Внешняя ссылка без `noreferrer` | Сторонний сайт получал адрес страницы | Добавлено `noopener noreferrer` |
| Устаревшая версия Playwright | Браузер в CI скачивался без проверки сертификата | Обновлено до 1.63 |

## Чего тесты не покрывают

Демо работает без сервера, поэтому серверные угрозы сейчас неприменимы. Для пилота с сервером нужны отдельные проверки: авторизация и права доступа, защита от подбора кода из SMS, ограничение частоты запросов, защита от ботов при голосовании, хранение данных в России, журналы доступа к персональным данным.
