# Проверки VoteConnect

Из папки `tests` выполни `npm ci` и `npx playwright test`. GitHub Actions запускает эти тесты и аудит зависимостей при отправке изменений.

- `security.spec.js` проверяет отсутствие сторонних запросов, локальную отправку голоса, CSP, безопасные внешние ссылки, данные из браузера, квитанцию и загрузку всех страниц.
- `static.spec.js` проверяет скрипты, стили, собственный кэш, отсутствие секретов и пометку о вымышленных данных.
- `regress.spec.js` проверяет голосование, сброс демо, отбор проектов по бюджету, клавиатуру, печать и адаптивность.
